# Descomplicando Clean Architecture, DDD e TDD em Python
Neste projeto Python, abordamos de forma prática os conceitos de **Clean Architecture**, **Domain-Driven Design (DDD)** e **Test-Driven Development (TDD)**, solucionando um desafio para uma vaga de backend no PicPay. Além disso, você aprenderá a aplicar técnicas como **Example Mapping** para entender requisitos, modelar domínios e implementar princípios **SOLID** e **Design Patterns**.

## 📦 Instalação

Siga os passos abaixo para rodar este projeto localmente:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/costanonato/desafio-picpay-ddd-clean-architecture-tdd
   ```
2. **Acesse o diretório do projeto:**
   ```bash
   cd desafio-picpay-ddd-clean-architecture-tdd
   ```
3. **Crie e ative um ambiente virtual:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # No Windows: venv\Scripts\activate
   ```
4. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```
5. **Execute os testes:**
   ```bash
   pytest
   ```

### Funcionalidades Principais

- **Transferência de Dinheiro:** Implementação do caso de uso `TransferMoney` seguindo os princípios de Clean Architecture.
- **Modelagem de Domínio:** Utilização do DDD Tático para modelar as entidades e agregados.
- **Testes Automatizados:** Cobertura de testes com TDD para garantir a qualidade do código.
